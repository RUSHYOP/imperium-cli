## What is Imperium?

**Imperium** is a CLI that gives your AI agent superpowers. It installs curated knowledge packs, tool connections, and pre-built configurations into your agent — so it writes better code, follows your patterns, and connects to your tools.

Think of it as an **app store for your AI agent's brain**.

```bash [Terminal]
npm install -g @rushy/imperium-cli
```

## Why do I need this?

AI agents like Claude, Copilot, and Cursor are powerful — but out of the box, they don't know your stack. They don't know your coding patterns, your team's conventions, or how to talk to your tools.

You could write custom instructions from scratch and copy files between projects. Or you could let Imperium do it in seconds:

```bash [Terminal]
# Give your agent Python expertise
imperium add skills python-patterns

# Or set up everything at once
imperium setup claude --preset fullstack
```

## Supported agents

| Agent | How it's set up | Command |
|-------|----------------|---------|
| Claude | `.claude/` folder | `imperium setup claude` |
| GitHub Copilot | `.github/copilot/` folder | `imperium setup github` |
| Cursor | `.cursor/` folder | `imperium setup cursor` |
| Windsurf | `.windsurf/` folder | `imperium setup windsurf` |
| Custom | Your choice | `imperium setup custom --root ./my-agent` |

## How it works

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   Registry  │────▶│  Installer  │────▶│   Adapter   │
│  (GitHub)   │     │  (fetcher)  │     │  (platform) │
└─────────────┘     └─────────────┘     └─────────────┘
 121+ skills         Fetches files       Writes to the
                     Updates lockfile    right folder
 Presets              Verifies checksums  (.claude, .cursor…)
```

1. **Registry** — A GitHub repo containing all available skills and presets
2. **Installer** — Fetches content on demand, writes files, and tracks everything in a lockfile
3. **Adapter** — Knows how each agent platform structures its files and installs accordingly
