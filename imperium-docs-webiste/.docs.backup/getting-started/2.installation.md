## Prerequisites

- **Node.js** 18 or later
- **npm** (comes with Node.js)

## Install

```bash [Terminal]
npm install -g @rushy/imperium-cli
```

## Verify

```bash [Terminal]
imperium --version
```

## Explore

```bash [Terminal]
imperium --help
```

The help system is colorized and guided — it shows you where to start, what's available, and how to use each command.

## Your first project

::steps
### Set up your agent

```bash [Terminal]
imperium setup claude
```

Creates everything your agent needs — folders, settings, and a ready-to-use context directory.

### See what's available

```bash [Terminal]
imperium list skills
```

Browse 121+ knowledge packs covering Python, Django, Go, Kotlin, frontend, testing, security, and more.

### Install a knowledge pack

```bash [Terminal]
imperium add skills python-patterns
```

Your agent instantly knows idiomatic Python patterns, best practices, and coding conventions.

::

## Update

```bash [Terminal]
npm update -g @rushy/imperium-cli
```

## Uninstall

```bash [Terminal]
npm uninstall -g @rushy/imperium-cli
```
