## Usage

```bash [Terminal]
imperium update [skills...] [flags]
```

## Arguments

| Argument | Required | Description |
|----------|----------|-------------|
| `skills...` | No | Specific skills to update. Omit to update all installed skills. |

## Flags

All [target](/getting-started/flags#target-flags), [write](/getting-started/flags#write-strategy-flags), [registry](/getting-started/flags#registry-flags), and [output](/getting-started/flags#output-flags) flags are available.

## Examples

### Update all installed skills

```bash [Terminal]
imperium update
```

### Update specific skills

```bash [Terminal]
imperium update python-patterns
```

### Update multiple skills

```bash [Terminal]
imperium update python-patterns django-tdd
```

### Preview updates without applying

```bash [Terminal]
imperium update --dry-run
```

### Update from a pinned tag

```bash [Terminal]
imperium update --tag v1.2.0
```

### Skip all prompts

```bash [Terminal]
imperium update -y
```
