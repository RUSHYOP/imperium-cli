## What is the lockfile?

Every time you install or remove something, Imperium updates `imperium.lock.json` in your project. This file records exactly what's installed, where it came from, and when it was last synced.

Think of it like `package-lock.json` for your agent's knowledge.

## Lockfile structure

```json [imperium.lock.json]
{
  "version": 1,
  "preset": "claude",
  "root": ".claude",
  "packages": {
    "python-patterns": {
      "name": "python-patterns",
      "kind": "skill",
      "version": "0.0.0",
      "source": "github:RUSHYOP/imperium-cli",
      "checksum": "a1b2c3d4e5f6...",
      "installedPath": ".claude/skills/python-patterns",
      "installedAt": "2026-03-19T00:00:00.000Z",
      "lastSync": "2026-03-19T00:00:00.000Z"
    }
  }
}
```

| Field | Description |
|-------|-------------|
| `version` | Lockfile format version |
| `preset` | Which adapter was used during setup |
| `root` | The agent folder root (e.g., `.claude`) |
| `packages` | Map of every installed item with metadata |

Each package entry tracks:

- **name** — Registry identifier
- **kind** — `skill`, `reference`, or `preset`
- **source** — Where it was fetched from
- **checksum** — Content hash for integrity verification
- **installedPath** — Where the files live on disk
- **installedAt** — First install timestamp
- **lastSync** — Last update timestamp

## Creating a lockfile

```bash [Terminal]
# Auto-create during setup
imperium setup claude

# Or initialize manually
imperium init
```

## Team sharing

Commit `imperium.lock.json` to version control. When a teammate clones the repo, they can see exactly what's installed and verify integrity:

```bash [Terminal]
imperium validate
```

## Validation

`imperium validate` compares installed files against the lockfile:

```bash [Terminal]
# Check everything
imperium validate

# Verbose output — shows each file
imperium validate --verbose
```

| Status | Meaning |
|--------|---------|
| Pass | All files match their recorded checksums |
| Fail — file modified | A skill file was edited outside Imperium |
| Fail — file missing | A tracked file was deleted |
| Fail — stale lockfile | Lockfile references items that don't exist |

### Fixing validation failures

```bash [Terminal]
# File was manually edited — preserve your changes on next update
imperium update --preserve

# File was deleted — reinstall it
imperium add skills python-patterns

# Stale lockfile — regenerate
imperium init
```
