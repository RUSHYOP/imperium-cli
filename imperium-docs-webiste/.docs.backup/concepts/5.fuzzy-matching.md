## How it works

Imperium uses **Levenshtein distance** to detect typos in commands, skill names, and adapter names. When you make a mistake, it suggests the closest match instead of failing silently.

## Command typos

```bash [Terminal]
$ imperium dowload test
⚠ Unknown command 'dowload'. Did you mean 'download'?
```

## Skill name typos

```bash [Terminal]
$ imperium add skills opneapi
⚠ 'opneapi' not found — using 'openapi' instead.
```

## Adapter typos

```bash [Terminal]
$ imperium setup .claud
⚠ '.claud' not found — using '.claude' instead.
```

## Disabling fuzzy correction

If you want exact matching only (useful for CI/CD scripts):

```bash [Terminal]
imperium add skills python-patterns --no-fuzzy
```

The `--no-fuzzy` flag disables all automatic correction. The command will fail with an error instead of suggesting alternatives.
