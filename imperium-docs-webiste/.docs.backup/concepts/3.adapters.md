## Pick your agent

Imperium knows how to set up each of these AI agents. Run `imperium setup <agent>` and the right folder structure is created automatically.

### Claude

```bash [Terminal]
imperium setup claude
```

Creates:

```
.claude/
├── settings/
├── commands/
└── skills/          # ← knowledge packs go here
```

---

### Custom

```bash [Terminal]
imperium setup custom --root ./my-agent
```

For agents not in the list above. Point Imperium at your own directory and it installs packs there.

## Detect what's already set up

Working in a project that already has agent folders?

```bash [Terminal]
imperium detect
```

Scans the current directory and tells you which agents are configured.

## Target a specific agent

When you have multiple agent folders in the same project, tell Imperium which one to use:

```bash [Terminal]
# Install packs into Claude specifically
imperium add skills python-patterns --target claude

# Initialize the lockfile for Copilot
imperium init --target github
```
