## How it works

Imperium ships with a **built-in catalog** of every available knowledge pack and preset. When you run `imperium list skills`, there's no network call — the catalog is read instantly from the local package.

Actual file contents are fetched **from GitHub on demand** when you install something with `imperium add` or `imperium setup --preset`.

## What's in the registry

| Catalog | Contents | Count |
|---------|----------|-------|
| Knowledge Packs | Agent instructions for coding, testing, design, security, and more | 118+ |
| MCP Servers | Pre-configured tool connections (Obsidian, Atlassian, Miro, etc.) | 6 |
| Instructions | Standalone instruction files for top-level agent guidance | 1 |
| Presets | Curated bundles of packs + MCP servers + config files | Growing |

## Browsing the registry

```bash [Terminal]
# See all knowledge packs
imperium list skills -d

# See all MCP servers
imperium list mcps -d

# See all presets
imperium list presets

# Search for something specific
imperium search skills "api design"

# View full details
imperium inspect skills python-patterns
```

## Using a local registry

For testing or private knowledge packs, point Imperium at a local directory:

```bash [Terminal]
imperium list skills --local ./my-skills
imperium add skills my-custom-skill --local ./my-skills
```

## Version pinning

Pin to a specific release for reproducibility:

```bash [Terminal]
# Pin to a tag
imperium add skills python-patterns --tag v1.2.0

# Use beta channel
imperium add skills python-patterns --channel beta
```
