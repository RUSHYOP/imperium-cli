## The fastest way: use a preset

A preset installs everything at once — knowledge packs, tool connections, and config files — in a single command.

```bash [Terminal]
imperium setup claude --preset fullstack
```

That's it. Your agent now has a full-stack development setup with Python, testing, security, and frontend patterns.

## Build your own setup

Prefer picking exactly what you want? Follow these steps:

::steps
### Set up your agent environment

```bash [Terminal]
imperium setup claude
```

This creates the folder structure your agent needs.

### Browse what's available

```bash [Terminal]
imperium list skills -d
```

See all 118+ knowledge packs with descriptions.

### Install the packs you need

```bash [Terminal]
imperium add skills python-patterns django-tdd python-testing
```

### Verify everything is in sync

```bash [Terminal]
imperium validate
```
::

## Add MCP tool connections

Connect your agent to external tools with pre-configured MCP servers:

```bash [Terminal]
imperium add mcps obsidian pdf-reader
```

See all available MCP servers:

```bash [Terminal]
imperium list mcps -d
```

## Combine presets with extras

Start from a preset and layer on additional packs:

```bash [Terminal]
imperium setup claude --preset fullstack --with python-testing security-review
```

Or use `--with` during setup to add skills without a preset:

```bash [Terminal]
imperium setup claude --with python-patterns django-tdd
```

## Detect existing projects

Already have agent folders in your project? Imperium can find them:

```bash [Terminal]
imperium detect
```

## Preview before writing

Every command supports `--dry-run` — see exactly what would happen without touching any files:

```bash [Terminal]
imperium setup claude --preset fullstack --dry-run
imperium add skills python-patterns --dry-run
imperium remove skills golang-patterns --dry-run
```

## Real-world workflows

### Python backend project

```bash [Terminal]
imperium setup claude
imperium add skills python-patterns django-tdd python-testing api-design
imperium add mcps obsidian
```

### Frontend project

```bash [Terminal]
imperium setup cursor
imperium add skills react-patterns frontend-patterns typescript-patterns
imperium add mcps react-grab-mcp screenshot-server
```

### Full-stack with a team

```bash [Terminal]
imperium setup claude --preset fullstack --with security-review
# Commit imperium.lock.json to git
# Teammates run: imperium validate
```
