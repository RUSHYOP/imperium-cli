## Prerequisites

- **Node.js** 18 or later
- **npm** (comes with Node.js)

## Install

```bash [Terminal]
npm install -g @rushy/imperium-cli
```

## Verify

```bash [Terminal]
imperium --version
```

You should see the installed version number printed. If you get `command not found`, see the [Troubleshooting](/getting-started/troubleshooting) guide.

## Update

```bash [Terminal]
npm update -g @rushy/imperium-cli
```

## Uninstall

```bash [Terminal]
npm uninstall -g @rushy/imperium-cli
```
