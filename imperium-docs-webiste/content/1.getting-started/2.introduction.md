## What is Imperium?

**Imperium** is a package manager for AI agent context. It installs curated knowledge packs, custom instruction files, MCP server configurations, and pre-built agent environments — so your agent writes better code, follows your patterns, and connects to your tools from day one.

Think of it as an **app store for your AI agent's brain**.

## The problem it solves

AI agents like Claude, Copilot, and Cursor are powerful — but out of the box they're blank slates. They don't know your stack, your team's conventions, or how to interact with your tools. Every new project means starting over: writing custom instructions, copying files, and hoping nothing drifts out of sync.

Imperium solves this at the source. Instead of writing instructions that live only in one project, you install verified, versioned knowledge packs that work across every project and every agent you use. Your entire team gets the same setup in seconds.

## How it works

::steps
### You run a command

You tell Imperium what you want — a preset, a skill, an MCP server. Imperium reads its local catalog to resolve the request instantly, no network call needed for browsing.

### Imperium fetches from the registry

Actual content is pulled from the GitHub registry on demand. Files are downloaded, checksums are verified, and everything is tracked in a `imperium.lock.json` lockfile.

### Files land in the right place

Imperium's adapter layer knows exactly where each agent expects its files. It creates the correct folder structure, writes the content, and your agent picks it up on next launch.

### Your team stays in sync

Commit the lockfile. Teammates run `imperium validate` to verify their setup matches. Run `imperium update` to pull the latest versions.
::
