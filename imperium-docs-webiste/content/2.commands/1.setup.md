## Usage

```bash [Terminal]
imperium setup [adapter] [flags]
```

## Arguments

| Argument | Required | Values |
|----------|----------|--------|
| `adapter` | No | `claude`, `github`, `windsurf`, `cursor`, `custom` |

If `--preset` is provided and `adapter` is omitted, the adapter is **inferred from the preset definition**.

## Flags

| Flag | Description |
|------|-------------|
| `--preset <name>` | Apply a named setup preset (skills + config files) |
| `--with <skills...>` | Install additional skills after scaffolding |
| `--instructions <names...>` | Install custom instruction files after scaffolding |

Plus all [target](/getting-started/flags#target-flags), [write](/getting-started/flags#write-strategy-flags), [registry](/getting-started/flags#registry-flags), and [output](/getting-started/flags#output-flags) flags.

## What it does

1. Creates the adapter folder structure (e.g., `.claude/` with `settings/`, `commands/`)
2. If `--preset` is given: installs all skills, copies all config files from the preset
3. If `--with` is given: installs the extra skills on top
4. If `--instructions` is given: installs the named instruction files into the adapter-correct location

## Examples

### Basic scaffold

```bash [Terminal]
# Claude project
imperium setup claude

# GitHub Copilot project
imperium setup github

# Cursor project
imperium setup cursor
```

### With a preset

```bash [Terminal]
# Scaffold + apply a curated bundle
imperium setup claude --preset fullstack

# Let the preset determine the adapter
imperium setup --preset fullstack
```

### With extra skills

```bash [Terminal]
# Scaffold + install specific skills
imperium setup claude --with python-patterns django-tdd

# Preset + extra skills on top
imperium setup claude --preset fullstack --with security-review
```

### With instructions

```bash [Terminal]
# Scaffold + install custom instruction files
imperium setup claude --instructions coding-standards

# Combine preset, extra skills, and instructions
imperium setup claude --preset fullstack --with security-review --instructions coding-standards api-design
```

### Safety and preview

```bash [Terminal]
# Preview what would be created
imperium setup claude --dry-run

# Force overwrite existing folder
imperium setup claude --force

# Skip all Y/N prompts
imperium setup claude -y
```

### Advanced

```bash [Terminal]
# Custom project root
imperium setup claude --root /path/to/project

# Pin to a specific version
imperium setup claude --tag v1.2.0

# Use beta channel
imperium setup claude --channel beta

# Copy files instead of symlinking
imperium setup claude --copy
```
