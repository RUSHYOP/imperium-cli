## Usage

```bash [Terminal]
imperium list <type> [flags]
```

## Arguments

| Argument | Required | Values |
|----------|----------|--------|
| `type` | Yes | `skills`, `presets`, `instructions` (and singular aliases) |

## Command-specific flags

| Flag | Description |
|------|-------------|
| `-d, --description [items...]` | Show descriptions. Optionally pass specific item names. |

Plus all [query](/getting-started/flags#query-flags) and [output](/getting-started/flags#output-flags) flags.

## Examples

### List all skills

```bash [Terminal]
imperium list skills
```

### List skills with descriptions

```bash [Terminal]
imperium list skills -d
```

### Show description for specific items only

```bash [Terminal]
imperium list skills -d python-patterns django-tdd
```

### Filter by kind

```bash [Terminal]
imperium list skills --kind reference
```

### List setup presets

```bash [Terminal]
imperium list presets
```

### Output as JSON

```bash [Terminal]
imperium list skills --format json
```

### List instructions

```bash [Terminal]
imperium list instructions
```

### Output as YAML

```bash [Terminal]
imperium list presets --format yaml
```
