## init

Initialize an Imperium lockfile in a project. The lockfile tracks installed skills and their versions.

### Usage

```bash [Terminal]
imperium init [flags]
```

### Flags

[Target](/getting-started/flags#target-flags) and [output](/getting-started/flags#output-flags) flags.

### Examples

```bash [Terminal]
# Init in the auto-detected agent folder
imperium init

# Init for a specific adapter
imperium init --target claude

# Init in a custom path
imperium init --root /path/to/project
```

## detect

Scan the current directory for known agent configuration folders.

### Usage

```bash [Terminal]
imperium detect [flags]
```

Detects: `.claude/`, `.github/`, `.cursor/`, `.windsurf/`, and custom folders.

### Flags

[Output](/getting-started/flags#output-flags) flags only.

### Examples

```bash [Terminal]
# Scan for agent folders
imperium detect

# Verbose output
imperium detect --verbose
```

## validate

Validate that installed skills match the lockfile manifest.

### Usage

```bash [Terminal]
imperium validate [flags]
```

### Flags

[Target](/getting-started/flags#target-flags) and [output](/getting-started/flags#output-flags) flags.

### Examples

```bash [Terminal]
# Validate the auto-detected lockfile
imperium validate

# Validate a specific adapter
imperium validate --target claude

# Full detail output
imperium validate --verbose

# Custom path
imperium validate --root /path/to/project
```

### When validation fails

| Cause | Fix |
|-------|-----|
| Skill file manually edited | Use `--preserve` on next update |
| Skill removed outside Imperium | `imperium add skills <name>` to reinstall |
| Stale lockfile | `imperium init` to regenerate |
