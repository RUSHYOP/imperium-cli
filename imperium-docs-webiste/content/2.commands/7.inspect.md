## Usage

```bash [Terminal]
imperium inspect <type> <name> [flags]
```

## Arguments

| Argument | Required | Description |
|----------|----------|-------------|
| `type` | Yes | `skills`, `presets`, `instructions` |
| `name` | Yes | Exact item name |

## Flags

All [query](/getting-started/flags#query-flags) and [output](/getting-started/flags#output-flags) flags are available.

## Examples

### Inspect a skill

Shows full content and metadata:

```bash [Terminal]
imperium inspect skills python-patterns
```

### Inspect a setup preset

Shows included skills and files:

```bash [Terminal]
imperium inspect presets fullstack
```

### Output as YAML

```bash [Terminal]
imperium inspect skills python-patterns --format yaml
```

### Inspect an instruction

```bash [Terminal]
imperium inspect instructions coding-standards
```

### Output as JSON

Useful for scripts and automation:

```bash [Terminal]
imperium inspect skills python-patterns --format json
```
