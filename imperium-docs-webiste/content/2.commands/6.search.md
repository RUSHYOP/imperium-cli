## Usage

```bash [Terminal]
imperium search <type> <query> [flags]
```

## Arguments

| Argument | Required | Description |
|----------|----------|-------------|
| `type` | Yes | `skills`, `presets`, `instructions` |
| `query` | Yes | Search keyword or quoted phrase |

## Flags

All [query](/getting-started/flags#query-flags) and [output](/getting-started/flags#output-flags) flags are available.

## Examples

### Search skills by keyword

```bash [Terminal]
imperium search skills python
```

### Multi-word search

```bash [Terminal]
imperium search skills "api design"
```

### Search presets

```bash [Terminal]
imperium search presets design
```

### Output as JSON

```bash [Terminal]
imperium search skills backend --format json
```

### Search instructions

```bash [Terminal]
imperium search instructions "coding standards"
```

### Filter by kind

```bash [Terminal]
imperium search skills testing --kind reference
```
