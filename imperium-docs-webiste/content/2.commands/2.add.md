## Usage

```bash [Terminal]
imperium add <type> [names...] [flags]
```

## Arguments

| Argument | Required | Description |
|----------|----------|-------------|
| `type` | Yes | `skills`, `mcps`, `instructions` (and singular aliases) |
| `names...` | Varies | One or more item names. Not required if `--all` or `--from-file` is used. |

::warning
`imperium add presets` is **not supported**. Use `imperium setup --preset <name>` to apply a preset.
::

## Command-specific flags

| Flag | Description |
|------|-------------|
| `--from-file <path>` | Read skill names from a text file (one per line) — skills only |
| `--all` | Install all items from the registry — skills only |
| `--path <dir>` | Target directory (overrides `--root`) |

Plus all [target](/getting-started/flags#target-flags), [write](/getting-started/flags#write-strategy-flags), [registry](/getting-started/flags#registry-flags), [filter](/getting-started/flags#filter-flags), and [output](/getting-started/flags#output-flags) flags.

## Examples

### Install a single skill

```bash [Terminal]
imperium add skills python-patterns
```

### Install multiple skills

```bash [Terminal]
imperium add skills python-patterns django-tdd golang-patterns
```

### Install all skills from the registry

```bash [Terminal]
imperium add skills --all
```

### Install from a file list

Create a text file with one skill name per line:

```txt [skills.txt]
python-patterns
django-tdd
python-testing
security-review
```

```bash [Terminal]
imperium add skills --from-file skills.txt
```

### Install into a specific folder

```bash [Terminal]
imperium add skills python-patterns --path .cursor
```

### Preview the install

```bash [Terminal]
imperium add skills python-patterns --dry-run
```

### Pin to a version

```bash [Terminal]
imperium add skills python-patterns --tag v1.2.0
```

### Only install markdown files

```bash [Terminal]
imperium add skills python-patterns --include "*.md"
```

### Install a custom instruction

Instruction files are placed in the adapter-correct location (e.g., `CLAUDE.md` for Claude, `copilot-instructions.md` for GitHub Copilot, `rules/<name>.md` for Cursor/Windsurf).

```bash [Terminal]
imperium add instructions coding-standards
```

### Install multiple instructions

```bash [Terminal]
imperium add instructions coding-standards api-design
```

### Install an MCP server

```bash [Terminal]
imperium add mcps obsidian
```

### Install multiple MCP servers

```bash [Terminal]
imperium add mcps obsidian pdf-reader miro-mcp
```
