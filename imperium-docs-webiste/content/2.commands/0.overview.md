## Command skeleton

Every Imperium command follows the same pattern:

```bash [Terminal]
imperium <command> [type] [names...] [flags]
```

| Part | Description | Example |
|------|-------------|---------|
| `command` | The action to perform | `setup`, `add`, `remove`, `update` |
| `type` | What kind of item | `skills`, `presets`, `instructions` |
| `names...` | One or more item names | `python-patterns django-tdd` |
| `flags` | Options that modify behavior | `--dry-run`, `--force`, `-y` |

Not every command uses every part. Here's the full map:

## Full command map

```
imperium
├── setup [adapter] [flags]              # Scaffold an agent environment
│   ├── --preset <name>                  #   Apply a curated preset
│   ├── --with <skills...>               #   Add extra skills on top
│   └── --instructions <names...>        #   Install custom instruction files
│
├── add <type> [names...] [flags]        # Install skills or instructions
│   ├── --all                            #   Install every item
│   ├── --from-file <path>               #   Read names from a file
│   └── --path <dir>                     #   Custom target directory
│
├── remove <type> <names...> [flags]     # Uninstall skills or instructions
│
├── update [skills...] [flags]           # Update installed skills
│
├── list <type> [flags]                  # Browse the registry
│   └── -d, --description               #   Show descriptions
│
├── search <type> <query> [flags]        # Search by keyword
│
├── inspect <type> <name> [flags]        # View full metadata
│
├── init [flags]                         # Initialize a lockfile
├── detect [flags]                       # Scan for agent folders
└── validate [flags]                     # Verify lockfile integrity
```

## Commands by category

### Build your project

| Command | What it does | Example |
|---------|-------------|---------|
| [`setup`](/commands/setup) | Scaffold an agent environment | `imperium setup claude` |
| [`add`](/commands/add) | Install skills or instructions | `imperium add skills python-patterns` |
| [`remove`](/commands/remove) | Uninstall skills or instructions | `imperium remove skills golang-patterns` |
| [`update`](/commands/update) | Update to latest versions | `imperium update` |

### Explore the registry

| Command | What it does | Example |
|---------|-------------|---------|
| [`list`](/commands/list) | Browse all available items | `imperium list skills -d` |
| [`search`](/commands/search) | Find items by keyword | `imperium search skills "api design"` |
| [`inspect`](/commands/inspect) | View full item metadata | `imperium inspect skills python-patterns` |

### Project housekeeping

| Command | What it does | Example |
|---------|-------------|---------|
| [`init`](/commands/utilities) | Create a lockfile | `imperium init` |
| [`detect`](/commands/utilities) | Find existing agent folders | `imperium detect` |
| [`validate`](/commands/utilities) | Check installed files match lockfile | `imperium validate` |

## Global flags

Every command accepts these flags. See the full [Flags Reference](/getting-started/flags) for details.

| Flag | Description |
|------|-------------|
| `--dry-run` | Preview changes without writing files |
| `--force` | Overwrite existing files |
| `-y, --yes` | Skip confirmation prompts |
| `--verbose` | Detailed output |
| `--silent` | Suppress non-error output |
| `--root <path>` | Override project root |
| `--target <adapter>` | Target a specific agent platform |

## Typical workflow

```bash [Terminal]
# 1. Scaffold your agent
imperium setup claude

# 2. Add the skills you need
imperium add skills python-patterns django-tdd security-review

# 3. Or use a preset for everything at once
imperium setup claude --preset fullstack

# 4. Keep skills up to date
imperium update

# 5. Share with your team via lockfile
imperium validate
```
