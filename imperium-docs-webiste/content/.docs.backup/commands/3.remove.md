## Usage

```bash [Terminal]
imperium remove <type> <names...> [flags]
```

## Arguments

| Argument | Required | Description |
|----------|----------|-------------|
| `type` | Yes | `skills` (or `skill`) |
| `names...` | Yes | One or more item names to remove |

::warning
`imperium remove presets` is **not supported**. Remove individual skills instead.
::

## Flags

All [target](/getting-started/flags#target-flags), [write](/getting-started/flags#write-strategy-flags), and [output](/getting-started/flags#output-flags) flags are available.

## Examples

### Remove a skill

```bash [Terminal]
imperium remove skills python-patterns
```

### Remove multiple skills

```bash [Terminal]
imperium remove skills python-patterns django-tdd golang-patterns
```

### Preview what would be removed

```bash [Terminal]
imperium remove skills python-patterns --dry-run
```

### Remove without confirmation

```bash [Terminal]
imperium remove skills python-patterns -y
```
