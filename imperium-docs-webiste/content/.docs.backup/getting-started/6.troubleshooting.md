## "command not found" after install

If `imperium` isn't recognized after installing:

1. Check your global bin path:
   ```bash [Terminal]
   npm config get prefix
   ```
2. Make sure that path's `bin/` directory is in your `$PATH`
3. On macOS with nvm:
   ```bash [Terminal]
   nvm use default
   npm install -g @rushy/imperium-cli
   ```

## Can't find a knowledge pack

Imperium has **fuzzy correction** — if you mistype a name, it suggests the closest match.

If a pack genuinely doesn't exist:

```bash [Terminal]
# Search by keyword
imperium search skills <keyword>

# List everything
imperium list skills
```

## Lockfile won't validate

`imperium validate` checks that installed files match the lockfile. Common fixes:

- **Manually edited a file?** Use `--preserve` on your next update to keep your changes
- **Deleted a file outside of Imperium?** Reinstall it: `imperium add skills <name>`
- **Stale lockfile?** Regenerate it: `imperium init`

## Permission errors on macOS

If you see `EACCES` errors:

```bash [Terminal]
mkdir -p ~/.npm-global
npm config set prefix '~/.npm-global'
export PATH=~/.npm-global/bin:$PATH
```

Add the `export` line to your `~/.zshrc` to make it permanent.
