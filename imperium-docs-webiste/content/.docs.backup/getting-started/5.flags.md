Every Imperium command accepts **global flags**. Individual commands add their own flags on top — documented on each command's page.

## Target flags

Control where files are installed.

| Flag | Type | Description |
|------|------|-------------|
| `--root <path>` | `string` | Override the project root directory |
| `--target <adapter>` | `string` | Target adapter: `claude`, `github`, `windsurf`, `cursor`, `custom` |

## Write strategy flags

Control how files are written when conflicts arise.

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--force` | `boolean` | `false` | Overwrite existing files without prompting |
| `--dry-run` | `boolean` | `false` | Preview all changes — no files are written |
| `-y, --yes` | `boolean` | `false` | Skip all yes/no confirmation prompts |
| `--no-fuzzy` | `boolean` | `false` | Disable automatic typo correction |
| `--copy` | `boolean` | — | Copy files instead of symlinking |
| `--symlink` | `boolean` | — | Symlink files where possible |
| `--merge` | `boolean` | — | Merge new content into existing files |
| `--overwrite` | `boolean` | — | Replace existing files entirely |
| `--preserve` | `boolean` | — | Skip files the user has edited |

## Registry flags

Control where skills are fetched from.

| Flag | Type | Description |
|------|------|-------------|
| `--local <path>` | `string` | Use a local directory as the registry source |
| `--tag <version>` | `string` | Pin to a specific git tag |
| `--channel <channel>` | `string` | Release channel: `stable`, `beta`, `dev` |

## Filter flags

Filter which files are affected.

| Flag | Type | Description |
|------|------|-------------|
| `--include <pattern>` | `string` | Only process files matching this glob |
| `--exclude <pattern>` | `string` | Skip files matching this glob |

## Query flags

Format and filter output.

| Flag | Type | Description |
|------|------|-------------|
| `--kind <kind>` | `string` | Filter by kind: `skill`, `reference`, `preset` |
| `--format <fmt>` | `string` | Output format: `md`, `yaml`, `json` |

## Output flags

Control verbosity.

| Flag | Type | Description |
|------|------|-------------|
| `--verbose` | `boolean` | Show detailed file-by-file output |
| `--silent` | `boolean` | Suppress all non-error output |
