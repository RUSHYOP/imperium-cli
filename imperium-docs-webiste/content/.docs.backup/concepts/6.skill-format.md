## Directory structure

Each skill is a folder in the registry containing at least one `SKILL.md` file:

```
python-patterns/
├── SKILL.md              # Main instructions (required)
├── examples/
│   ├── decorators.md     # Pattern examples
│   └── generators.md
├── rules/
│   └── naming.md         # Coding conventions
├── references/
│   └── stdlib.md         # Reference material
└── templates/
    └── project.md        # Starter templates
```

## SKILL.md frontmatter

Every `SKILL.md` uses YAML frontmatter to declare metadata:

```markdown [SKILL.md]
---
name: python-patterns
description: >
  Use when working on Python projects. Covers idiomatic patterns,
  project structure, and best practices.
kind: skill
---

# Python Patterns

Your AI agent instructions go here. Write them as if you're
briefing a senior developer who will follow your guidance exactly.

## Decorators
Use decorators for cross-cutting concerns like logging,
caching, and access control...
```

| Field | Required | Description |
|-------|----------|-------------|
| `name` | Yes | Unique identifier, must match the folder name |
| `description` | Yes | What the skill does and when to use it |
| `kind` | No | `skill` (default), `reference`, or `preset` |

## Subfolders

Skills can include optional subfolders:

| Folder | Purpose |
|--------|---------|
| `examples/` | Worked examples and pattern demonstrations |
| `rules/` | Coding conventions and constraints |
| `references/` | Background material and documentation |
| `templates/` | Starter code and project scaffolds |
| `scripts/` | Automation scripts |
| `evals/` | Test cases and evaluation criteria |

## Using a local registry

Test your own skills before publishing:

```bash [Terminal]
# Point Imperium at a local directory
imperium add skills my-custom-skill --local ./my-skills

# List from a local source
imperium list skills --local ./my-skills

# Inspect local skill metadata
imperium inspect skills my-custom-skill --local ./my-skills
```

## Custom registries

Point to any GitHub repo with a `skills/` directory:

```bash [Terminal]
imperium list skills --registry your-org/your-repo
imperium add skills my-skill --registry your-org/your-repo#dev
```
