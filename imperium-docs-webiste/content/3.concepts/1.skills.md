## What are knowledge packs?

A **knowledge pack** (called a "skill" in Imperium) is a set of curated instructions that teach your AI agent how to work with a specific technology, framework, or practice. Once installed, your agent reads these files and immediately applies the knowledge.

Think of it like giving your agent a cheat sheet — except it actually reads the whole thing.

## What's inside a pack

Each pack contains Markdown files with instructions, patterns, rules, and examples:

```
python-patterns/
├── SKILL.md              # Main instructions
├── examples/
│   ├── decorators.md     # Pattern examples
│   └── generators.md
└── rules/
    └── naming.md         # Coding conventions
```

## Browsing packs

```bash [Terminal]
# See everything available (118+ packs)
imperium list skills

# With descriptions
imperium list skills -d

# Search by keyword
imperium search skills "api design"

# View the full contents of a pack
imperium inspect skills python-patterns
```

## Installing packs

```bash [Terminal]
# One pack
imperium add skills python-patterns

# Several at once
imperium add skills python-patterns django-tdd security-review

# Everything in the registry
imperium add skills --all

# From a list file
imperium add skills --from-file my-skills.txt
```

## Removing packs

```bash [Terminal]
imperium remove skills python-patterns
```

## Updating packs

```bash [Terminal]
# Update all installed packs
imperium update

# Update specific ones
imperium update python-patterns django-tdd
```

## Write strategy

When installing packs, you can control how conflicts are handled:

```bash [Terminal]
# Overwrite existing files
imperium add skills python-patterns --overwrite

# Keep your manual edits
imperium add skills python-patterns --preserve

# Merge new content into existing files
imperium add skills python-patterns --merge

# Copy instead of symlink
imperium add skills python-patterns --copy
```
