## Claude

::badge{color="green"}
Fully Supported
::

`imperium setup claude` creates the following structure in your project root:

```
.claude/
├── rules/              # Project rules and constraints
├── commands/           # Custom slash commands
├── agents/             # ← Generated skill agent files land here
├── skills/             # ← Raw knowledge pack files land here
└── todos/              # Task tracking
```

### How skills are installed

When you run `imperium add skills <name>`, Imperium does two things:

**1. Writes the raw skill to `skills/`**

The skill's full content is written as a Markdown file inside `.claude/skills/`. Your agent can reference it directly.

**2. Generates a Claude agent file in `agents/`**

Imperium generates a native Claude agent file at `.claude/agents/<name>.md`:

```markdown [.claude/agents/python-patterns.md]
---
name: python-patterns
description: Idiomatic Python patterns, project structure, and best practices.
---

# Python Patterns

[skill content here...]
```

Claude reads these files automatically — each one becomes an available agent context. No manual wiring needed.

### Scaffold-only folders

These folders are created by `imperium setup claude` but not written to by the installer:

| Folder | Purpose |
|--------|---------|
| `rules/` | Project-level rules and constraints you write yourself |
| `commands/` | Custom slash commands for Claude |
| `todos/` | Task tracking files |
