## What are MCP servers?

The **Model Context Protocol** (MCP) lets AI agents interact with external tools and services. Instead of manually configuring JSON server definitions, Imperium ships pre-configured MCP server configs that wire into your agent with a single command.

## Available MCP servers

| Name | Description |
|------|-------------|
| `atlassian` | Connect to Atlassian Jira and Confluence via MCP remote proxy |
| `miro-mcp` | Interact with Miro boards — create diagrams, tables, docs, and read board content |
| `obsidian` | Read, search, and manage notes in an Obsidian vault |
| `pdf-reader` | Read PDF files and extract text, metadata, images, and page info |
| `react-grab-mcp` | Grab and inspect React component trees from running apps |
| `screenshot-server` | Take screenshots of screens, windows, and UI elements |

## Browsing MCP servers

```bash [Terminal]
# List all available MCP servers
imperium list mcps

# With descriptions
imperium list mcps -d

# View full details for a specific server
imperium inspect mcps obsidian
```

## Installing MCP servers

```bash [Terminal]
# Install a single MCP server
imperium add mcps obsidian

# Install multiple at once
imperium add mcps obsidian pdf-reader miro-mcp
```

## Configuration placeholders

Some MCP servers require configuration values specific to your environment — like file paths or API tokens. These are represented as **placeholders** in the format `{{PLACEHOLDER_NAME}}`.

When you install an MCP server with placeholders, Imperium will prompt you to provide the values:

```bash [Terminal]
imperium add mcps obsidian
# → Prompts for: OBSIDIAN_VAULT_PATH (Absolute path to your Obsidian vault)
```

Items with required configuration show a **`[requires config]`** badge when listed.

## Where MCP configs are installed

MCP server definitions are written as JSON and placed in the adapter-specific location:

| Agent | Location |
|-------|----------|
| Claude | `.claude/settings.local.json` under `mcpServers` |
| GitHub Copilot | `.github/copilot/mcp.json` |
| Cursor | `.cursor/mcp.json` |

## Using with presets

Presets can bundle MCP servers alongside skills. When you apply a preset that includes MCPs, they're installed automatically:

```bash [Terminal]
imperium setup claude --preset fullstack
```

## Using with setup

Add MCP servers during initial agent setup:

```bash [Terminal]
imperium setup claude --with python-patterns
imperium add mcps obsidian pdf-reader
```

## Removing MCP servers

```bash [Terminal]
imperium remove mcps obsidian
```
