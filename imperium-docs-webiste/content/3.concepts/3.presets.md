## What is a preset?

A **preset** is a curated bundle that sets up your agent with everything it needs for a specific workflow. Instead of installing packs and tools one by one, a preset does it all at once.

One command. Full stack.

```bash [Terminal]
imperium setup claude --preset fullstack
```

## What a preset includes

Each preset bundles:
- **Knowledge packs** — the agent instructions to install
- **MCP servers** — pre-configured tool connections
- **Config files** — rules, commands, reference docs, and settings to copy

## What happens when you apply one

When you run `imperium setup claude --preset fullstack`:

::steps
### Your agent environment is created
The `.claude/` folder structure is scaffolded.

### Knowledge packs are installed
All packs defined in the preset are fetched and placed in your agent's context folder.

### MCP servers are configured
Any MCP server definitions in the preset are wired into your agent's settings.

### Config files are copied
Any rules, commands, or settings files from the preset are added to your project.
::

## Browsing presets

```bash [Terminal]
# See all presets
imperium list presets

# Search
imperium search presets design

# View what's inside
imperium inspect presets fullstack
```

## Applying presets

```bash [Terminal]
# Specify your agent + preset
imperium setup claude --preset fullstack

# Let the preset pick the agent
imperium setup --preset fullstack

# Add extra packs on top
imperium setup claude --preset fullstack --with security-review

# Preview without writing
imperium setup --preset fullstack --dry-run
```

::tip
You can't `add` or `remove` a preset directly. Use `imperium setup --preset` to apply one, and `imperium remove skills` to remove individual items afterward.
::
