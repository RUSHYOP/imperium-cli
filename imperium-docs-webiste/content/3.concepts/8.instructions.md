## What are instructions?

**Instructions** are standalone Markdown files that provide top-level guidance to your AI agent. Unlike knowledge packs (which are directories of files installed into a `skills/` folder), an instruction file is placed at the adapter-specific root location where the agent reads it automatically.

Think of it as the **main rulebook** your agent follows for every conversation.

## How they differ from knowledge packs

| | Knowledge Packs | Instructions |
|-|----------------|--------------|
| **Format** | Directory of files | Single Markdown file |
| **Location** | `<agent>/skills/<name>/` | Adapter-specific root (see below) |
| **Purpose** | Deep-dive topic expertise | Top-level project rules and guidelines |
| **Command** | `imperium add skills <name>` | `imperium add instructions <name>` |

## Where instructions are placed

Imperium knows the correct file path for each adapter:

| Adapter | Instruction file location |
|---------|--------------------------|
| Claude | `CLAUDE.md` |
| GitHub Copilot | `copilot-instructions.md` |
| Cursor | `rules/<name>.md` |
| Windsurf | `rules/<name>.md` |
| Custom | `rules/<name>.md` |

::note
For Claude and GitHub Copilot, instructions always write to a single fixed file. For Cursor, Windsurf, and Custom, each instruction creates a separate file in the `rules/` directory.
::

## Browsing instructions

```bash [Terminal]
# List all available instructions
imperium list instructions

# Search by keyword
imperium search instructions "coding standards"

# View the full content of an instruction
imperium inspect instructions coding-standards
```

## Installing instructions

```bash [Terminal]
# Install a single instruction
imperium add instructions coding-standards

# Install multiple instructions
imperium add instructions coding-standards api-design

# Install during setup
imperium setup claude --instructions coding-standards
```

## Removing instructions

```bash [Terminal]
imperium remove instructions coding-standards
```

## Using with setup

The `--instructions` flag on `imperium setup` installs instruction files after scaffolding. You can combine it with presets and extra skills:

```bash [Terminal]
# Full setup: adapter + preset + skills + instructions
imperium setup claude --preset fullstack --with security-review --instructions coding-standards api-design
```

## Creating your own instructions

To add an instruction to the Imperium registry, create a Markdown file in the `content/instructions/` directory with YAML frontmatter:

```md [content/instructions/coding-standards.md]
---
name: coding-standards
description: Team coding standards and conventions
---

# Coding Standards

Follow these conventions in all code you write...
```

The `name` and `description` fields in the frontmatter are used for registry listing, search, and display.
