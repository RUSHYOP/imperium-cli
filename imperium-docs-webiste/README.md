# imperium-cli docs

Documentation site for [imperium-cli](https://github.com/RUSHYOP/imperium-cli) — the package manager for AI agent context.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Built with [Docus](https://docus.dev) + [Nuxt 4](https://nuxt.com) + [Tailwind CSS 4](https://tailwindcss.com/).
