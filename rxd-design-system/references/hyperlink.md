# Hyperlink

Inline text link for navigation or actions.

## When to Use
- Navigating to another page or external resource
- Inline references within body text
- Secondary actions styled as links

## Properties

| Property | Options | Default |
|----------|---------|---------|
| Font Weight | Medium, Semibold | Medium |
| State | Default, Hover | Default |
| Size | Small, Medium | Small |

## Visual Variants (from Storybook)

| Story | What is visible |
|-------|----------------|
| default | "Hyperlink name" text in blue (`#0064D2`) with download icons on both sides (left: upload/link icon, right: download arrow icon); underline on hover implied |

### Visual notes
- Text colour: blue `#0064D2`
- Font weight: Medium (default) or Semibold
- Optional icons flanking the label; icons match text colour
- No background; renders inline within text content
- Size Small is visually compact; Medium is slightly larger
