# Infinite Scroll

Loading indicator for incrementally fetching content as the user scrolls.

## When to Use
- Long lists that load data on demand
- Social feeds or activity streams
- Replacing traditional pagination for continuous browsing

## Properties

| Property | Options | Default |
|----------|---------|---------|
| Theme | Neutral, Primary | Neutral |
| Size | Medium, Large, Small | Large |
| Type | Auto-Download, Manual Download | Auto-Download |
| Style | With Label, Without Label | With Label |

## Notes
- Auto-Download triggers automatically on scroll; Manual requires a user click
- With Label shows "Loading more..." text for clarity
