# Section (Header / Body / Footer)

Layout component for structuring page sections with a header, body, and footer.

## When to Use
- Page-level section layout
- Sectioned content with distinct header and footer areas
- Consistent section structure across views

## Sub-components
- **Header-Section** — section header area
- **Header-Left Section** — left-aligned header content
- **Header-Right** — right-aligned header content / actions
- **Body-Section** — main content area
- **Footer-Section** — footer area
