# TimePicker

Time-only selection input.

## When to Use
- Schedule or alarm time entry
- Meeting time selection
- Any time-only field (not combined with date)

## Properties

| Property | Options | Default |
|----------|---------|---------|
| State | Default, Active, Selected, Filled | Default |
| Type | With Tab | With Tab |

## Notes
- See also DateTimePicker when both date and time are needed
