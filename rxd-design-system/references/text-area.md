# TextArea

Multi-line text input for longer content entry.

## When to Use
- Comments, descriptions, and notes
- Multi-line form fields
- Any input requiring more than one line of text

## Properties

| Property | Options | Default |
|----------|---------|---------|
| Size | Regular, Small, Large | Small |
| State | Default, Filled, Focused, Success, Error, Disabled, Disabled Placeholder, Success Focused, Error Focused | Default |
