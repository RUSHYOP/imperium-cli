# QuickHelp

Contextual help panel with a menu of help topics.

## When to Use
- In-app help and guidance
- Contextual walkthroughs
- Feature discovery panels

## Sub-components
- **MenuItem** — individual help topic link
- **MenuItem-List** — grouped list of help topics

- MenuItem-List Set ID: `22258:32870`
