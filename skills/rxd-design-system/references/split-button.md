# SplitButton

Dual-action button with a primary action and a dropdown for secondary actions.

## When to Use
- Save / Save As patterns
- Primary action with alternatives (Send / Schedule)
- Compact multi-action controls

## Properties

| Property | Options | Default |
|----------|---------|---------|
| Variant | Primary, Secondary | Primary |
| Color | Primary, Neutral | Primary |
| Size | XSmall, Small, Medium, Large | XSmall |
| State | Default, Hover-Left, Hover-Right, Pressed-Left, Pressed-Right, Disable | Default |

## Notes
- Left side executes the default action; right side opens the dropdown
