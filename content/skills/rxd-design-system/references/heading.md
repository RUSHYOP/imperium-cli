# Heading

Typographic heading component for page and section titles (H1-H6).

## When to Use
- Page titles and section headers
- Card or panel titles
- Any hierarchical heading structure

## Properties

| Property | Options | Default |
|----------|---------|---------|
| Font Weight | Semi-bold, Bold | Semi-bold |
| Tag | H1, H2, H3, H4, H5, H6 | H1 |

## Notes
- Use semantic heading levels (H1 for page title, H2 for sections, etc.)
- Bold weight for extra emphasis when needed

## Visual Variants (from Storybook)

- **Default/Playground**: Renders bold dark navy text (color: neutral-900 `#182858`) with no surrounding decoration. Example shown: “Sample Heading” in semi-bold weight.
- The heading renders inline — no card, no border, no background. Pure typographic element.
- Font is Inter; heading appears noticeably larger and heavier than Paragraph or Label text at equivalent size settings.
