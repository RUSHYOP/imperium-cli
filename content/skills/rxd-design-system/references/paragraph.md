# Paragraph

Body text component with configurable weight and font size.

## When to Use
- Body copy and descriptive text
- Help text and instructions
- Any multi-line text content

## Properties

| Property | Options | Default |
|----------|---------|---------|
| Font Weight | Regular, Medium, Semibold | Regular |
| Font Size | Font-10 through Font-72 (16 sizes) | Font-10 |

- Component Set ID: `19110:8570`

## Visual Variants (from Storybook)

- **Playground**: The playground screenshot shows a large block of body text rendered at a readable size (~14-16px). Text is dark neutral (neutral-700/neutral-900). Multi-paragraph lorem ipsum content demonstrating line-height and paragraph spacing.
- The paragraph component is purely typographic — no borders, backgrounds, or decoration. It wraps naturally within its container width.
- Bold/medium weight variants render visually heavier but at the same size, useful for emphasis within body copy.
- Font-10 (10px) is the minimum — used for captions and fine print only. Font-16 is the standard body size.
