# Context Menu

Right-click or overflow menu with grouped actions. Supports nested menus and search filtering.

## When to Use
- Right-click contextual actions
- Overflow "more" menus on cards, rows, or toolbars
- Action lists with optional grouping and sub-text

## Properties

| Property | Options | Default |
|----------|---------|---------|
| With Search | True, False | False |

## Sub-components
- **Context Menu Base** — individual menu item row
- **Sub Text - Context Menu Base** — menu item with secondary description

## Notes
- Enable search for long action lists to help users find items quickly
