# Splitter

Draggable divider that resizes adjacent panels.

## When to Use
- Resizable panel layouts (editor + preview)
- Master-detail views with adjustable proportions
- IDE-style multi-pane interfaces

## Properties

| Property | Options | Default |
|----------|---------|---------|
| Orientation | Vertical, Horizontal | Vertical |
| Color | Primary, Neutral | Primary |
| State | Default, Hover, Pressed, Disable | Default |
| Navigation | On, Off | On |

## Sub-components
- **States Neutral** / **States Primary** — themed handle states

## Notes
- Navigation toggle adds collapse/expand arrows to the splitter handle
