# Rich Text Box

WYSIWYG rich text editor with formatting toolbar.

## When to Use
- Multi-line formatted content entry (descriptions, comments)
- Email composition
- Content management editors

## Properties

| Property | Options | Default |
|----------|---------|---------|
| Border | With Border, Without Border | With Border |
| Size | Small, Regular, Large | Regular |
