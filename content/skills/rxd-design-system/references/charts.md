# Charts

Data visualisation component supporting a wide range of chart types and colour themes.

## When to Use
- Dashboards and analytics views
- Reporting and data comparison
- Trend visualisation over time

## Properties

| Property | Options | Default |
|----------|---------|---------|
| Theme | Vibrant, Light, Dark | Vibrant |
| Type | Line, Doughnut, Pie, Bar Vertical, Bar Horizontal, Double Bar Horizontal, Double Bar Vertical, Stacked Bar Horizontal, Stacked Bar Vertical, Scatter, Radial, Radar, Funnel, Area, Donut, Heatmap | Line |
| Color Scale | None, Sequential, Diverging, Categorical | None |

## Sub-components
- **Legends** — chart legend key for series/categories

## Notes
- 16 chart types available — choose based on data relationship (comparison, composition, distribution, trend)
- Color Scale adds semantic meaning — Sequential for magnitude, Diverging for positive/negative, Categorical for distinct groups
